## 当前项目已完成的安全桥接

新增执行端适配器：

```text
executor-client/src/adapters/SiyuAdapter.js
```

支持配置：

```json
{
  "dhAdapter": "siyu",
  "siyu": {
    "baseUrl": "",
    "healthUrl": "",
    "speakUrl": "",
    "timeoutMs": 8000
  }
}
```

当前行为：

- 未配置 `healthUrl` 时，只返回“未配置健康检查接口”。
- 未配置 `speakUrl` 时，只返回“未配置播报接口”。
- 不运行外部 exe。
- 不读取 siyuAI 配置文件。
- 不假设任何未确认的 API 参数。
- 一旦提供已确认的本地 HTTP API，可通过 `speak({ text, tone })` 做最小播报测试。

## 需要人工确认的 siyuAI API 信息

### 2. 文本播报接口

需要确认：

- 是否支持直接输入文本播报。

需要确认：

- TTS 是否由 siyuAI 内置。
- 是否需要先生成音频再喂给数字人。
- 口型同步是否自动完成。
- 单句文本到画面开始动的延迟。

### 4. 画面输出

需要确认：

- 输出方式：窗口、虚拟摄像头、NDI、RTMP、WebRTC、OBS 插件或浏览器源。

- 支持的分辨率和帧率。

### 5. 弹幕与语言层

需要确认：

- `tools/danmu_capture` 是否可独立运行。
- 是否提供弹幕回调或本地接口。

```json

  "dhAdapter": "siyu",
```

6. 后端收到 ack。
7. OBS 或虚拟摄像头确认画面变化。
