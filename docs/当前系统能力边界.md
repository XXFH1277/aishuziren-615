# 当前系统能力边界

本文档用于说明当前数字人直播带货中控系统原型已经完成什么、哪些能力仍然是本地 Mock，以及哪些内容暂时不能按真实服务理解。

## 当前已完成

### 前端后台

- React + Vite 后台原型。
- AdminLayout、Sidebar、Header、Breadcrumb、真实路由和多级菜单。
- Dashboard、商品管理、数字人管理、直播管理、直播间搭建、互动播控、直播中控台、AI 能力中心、执行端管理、帮助中心、系统设置。
- 主要页面具备 loading、error、empty 状态。
- 关键 Mock 边界页面已补充“当前为本地 Mock 占位，未接真实服务”提示。

### Service 层

当前主要业务页面遵循：

```text
页面组件 -> service 函数 -> 本地 API -> SQLite
```

已接入本地 API 的 service：

- `dashboardService`
- `productService`
- `avatarService`
- `liveService`
- `studioService`
- `interactionService`
- `delayControlService`
- `liveControlRoomService`
- `aiService`
- `executorService`
- `helpService`
- `settingsService`
- `authService`
- `fileService`

仍合理保留前端静态选项的内容：

- 下拉枚举。
- 标签状态选项。
- 表单预设选项。
- 页面演示用文案。

### Express 后端

- 本地 Node + Express API。
- CORS 支持。
- 统一响应格式。
- 统一错误码工具。
- 参数校验工具。
- 本地 Auth / RBAC MVP。
- 权限 key 工具。
- 操作日志工具占位。
- 当前不实现生产级登录安全、全量接口权限拦截或数据权限过滤。

### SQLite 数据库

- 本地 SQLite 数据库文件：`server/data/dev.sqlite`。
- `server/data/*.sqlite` 和 `server/data/*.db` 已要求忽略，不应提交。
- `npm run server:seed` 可重复初始化 Mock 数据。

- Live
- Studio

### Smoke Test

- `npm run server:smoke` 当前覆盖 76 项本地 API 检查。
- Smoke Test 使用 Node 原生 `fetch`，不引入 Jest / Vitest。
- Smoke Test 不连接真实外部服务。

### Dashboard / Auth / File API

- Dashboard 已通过 `GET /api/dashboard/overview` 读取本地聚合数据。
- Auth 已提供 `/api/auth/login`、`/api/auth/logout`、`/api/auth/me`、`/api/auth/refresh`，Phase 13 已升级为本地密码校验、Bearer token 和 SQLite session MVP。
- File 已提供 `POST /api/files/upload`，但当前只接受 JSON Mock 请求，不处理真实文件。

### API 错误态收口

`src/services/request.js` 已统一处理：

- 本地 API 未启动：提示“本地 API 服务未连接，请先运行 npm run server:dev”。
- 后端 `code !== 0`：展示 `message`，并补充 `error.field` / `error.reason`。
- 非 JSON 响应：提示本地 API 返回格式异常。

## 当前仍为 Mock

### 生产级登录

当前 `/api/auth/*` 已完成本地 Auth MVP，但仍不是生产级登录系统：

- 已校验 SQLite 中的本地密码 hash。
- 已生成本地 Bearer token，并只在数据库保存 token hash。
- 已做 SQLite session 管理和退出登录 token 作废。
- 未做 Cookie / CSRF 策略、登录限流、密码重置、多端会话管理或生产密钥轮换。

### 生产级权限

当前权限 key 已用于前端菜单 / 页面入口过滤，并在少量系统设置接口中示范校验：

- 尚未对所有业务 API 做强制权限拦截。
- 不做数据权限过滤。

### 真实文件上传

当前 `POST /api/files/upload` 是 Mock：

- 不解析 multipart。
- 不保存真实文件。
- 不上传云端。
- 不做病毒扫描、大小限制或鉴权校验。

### 真实模型调用

Kimi、Mimo、OpenAI、DeepSeek、通义千问等全部未接真实服务：

- 不读取 `模型api.txt`。
- 不读取 `.env.local`。
- 不保存真实 API Key。
- 不发起真实模型请求。
- 模型测试连接只返回 Mock。

### 真实 OBS

当前 OBS 相关页面和接口均为 Mock：

- 不连接 OBS WebSocket。
- 不读取真实 OBS 场景。
- 不控制真实来源。
- 不发送真实预览画面。

### 真实执行端

执行端管理仍为本地 Mock：

- 不存在 Electron / Tauri / Python 本地客户端。
- 不建立真实心跳。
- 不控制真实直播电脑。
- 重启、解绑、刷新配置只记录 Mock 指令。

### WebSocket

当前没有真实 WebSocket：

- 弹幕模拟使用 dev-only API。
- 执行端心跳为 SQLite Mock。
- 直播中控台实时感来自本地状态刷新和前端交互。

### 直播平台弹幕

当前不接抖音、快手、视频号、小红书、淘宝直播等平台接口：

- 无真实弹幕捕获。
- 无真实平台鉴权。
- 无真实直播间绑定。

### 数字人训练 / TTS / 口型同步

当前数字人相关能力均为原型：

- 不训练数字人。
- 不克隆声音。
- 不调用 TTS。
- 不做口型同步。
- 不输出真实数字人画面。

### 真实推流

当前不做真实推流：

- 不接云端推流。
- 不接直播伴侣。
- 不接虚拟摄像头。
- 不向任何平台推流。

## 不能误解为已完成的事项

- “AI 生成”按钮表示 Mock 生成，不代表已接模型服务。
- “测试连接”表示 Mock 测试，不代表已访问服务商。
- “执行端在线”表示本地 Mock 状态，不代表真实直播电脑在线。
- “OBS 已连接”表示本地 Mock 状态，不代表真实 OBS 可控。
- “加入待播队列”多数场景只写入本地 API Mock，不代表真实数字人会播报。
- “文件上传”当前只是 API 契约占位，不代表真实文件已存储。

## 安全边界

- 不提交 `.env.local`。
- 不提交 `模型api.txt`。
- 不提交 SQLite 数据库文件。
- 不把 API Key 写进前端。
- `VITE_` 环境变量会进入浏览器 bundle，不能放模型 Key。
- 真实模型调用必须后端代理，并增加脱敏、超时、限流、费用保护和审计策略。

## 当前适合做的验收

- 页面路由是否完整。
- 本地 API 是否可启动。
- SQLite seed 是否稳定。
- Smoke Test 是否通过。
- 页面 loading / error / empty 是否合理。
- Mock 边界提示是否清楚。
- 表单保存和本地 API 写入是否符合预期。

## 当前不适合做的验收

- 真实直播稳定性。
- 真实数字人播报效果。
- 真实 OBS 控制。
- 真实平台弹幕。
- 真实 AI 生成质量。
- 真实登录安全性。
- 真实文件上传安全性。
- 生产环境性能和权限隔离。
