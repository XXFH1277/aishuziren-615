## 3. 后端新增 / 调整接口

```text
POST /api/executors/bind-code
POST /api/executors/register
POST /api/executors/:id/heartbeat
GET  /api/executors/:id/commands/pending
POST /api/executors/commands/:id/ack
```

说明：
- `/api/executors/bind-code` 使用后台用户鉴权和执行端操作权限。
- `/api/executors/register` 使用一次性绑定码，不使用用户 token。
- 心跳、命令拉取、命令回执使用独立 device token。
- device token 明文只返回一次，数据库只保存 `device_token_hash`。
