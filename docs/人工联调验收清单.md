# 人工联调验收清单

本文档用于 Phase 12.20 之后的人工点击验收。当前系统默认本地链路为：

```text
前端页面 -> Service 层 -> 本地 Express API -> SQLite
```

## 联调前准备

在项目根目录依次执行：

```bash
npm install
npm run server:seed
npm run server:dev
npm run dev
```

建议另开终端执行：

```bash
npm run server:smoke
npm run build
```

默认地址：

- 前端：`http://127.0.0.1:5173`，如端口占用，Vite 会自动切换。
- 后端：`http://localhost:3000`

如果页面提示“本地 API 服务未连接，请先运行 npm run server:dev”，优先检查后端是否启动、端口是否被旧进程占用、是否已运行 `npm run server:seed`。
