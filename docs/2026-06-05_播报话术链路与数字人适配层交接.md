# 播报话术链路与数字人适配层交接

日期：2026-06-05

## 1. 本次目标

打通“后台下发话术 → 后端写入执行端命令 → 本地执行端拉取命令 → 数字人适配器处理 → 执行端回执 → 前端最近命令展示”的 MVP 链路。

本次不接真实 DUIX、TTS、口型同步、推流或直播平台，只建立可插拔的数字人引擎适配层。

## 2. 新增后端能力

接口：

```text
POST /api/executors/:id/speak
```

要求：

- 需要用户登录和人工接管权限（`live:manual-takeover`）。
- Body: `{ text, tone?, source? }`
- 写入 `executor_commands`，`command_type = speak`。
- 命令状态仍沿用 `pending -> succeeded/failed`。
- 执行端 `ack` 中的播报结果保存在 `ack_payload_json.detail`。

## 3. 执行端适配层

新增接口形态：

```js
DigitalHumanAdapter = {
  init(config),
  speak({ text, tone }),
  getStatus(),
  dispose()
}
```

当前实现：

- `PrintAdapter`：默认适配器，只在终端打印话术并模拟播报成功。
- `DuixAdapter`：占位适配器，不调用真实 DUIX API，只返回“未配置/待核实”结果。

配置：

```text
DH_ADAPTER=print
DH_ADAPTER=duix
```

也可写入 `executor-client/config.local.json` 的 `dhAdapter` 字段。`config.local.json` 不入仓库。

## 4. 前端入口

执行端列表页新增“测试播报”操作：

- 输入测试话术。
- 选择语气。
- 调用 `executorService.sendExecutorSpeak()`。
- 后端写入 `speak` 命令。
- 最近命令列可看到 `speak` 命令状态。

## 5. 端到端验收路径

1. 启动后端。
2. 前端登录后进入执行端列表，生成绑定码。
3. 用绑定码启动 `executor-client`。
4. 前端执行端列表看到设备在线，心跳持续刷新。
5. 在执行端列表点击“测试播报”，输入一句话术并下发。
6. `PrintAdapter` 在执行端终端打印话术。
7. 执行端回执 `succeeded`，detail 中包含 `adapter=print`、`startedAt`、`durationMs`。
8. 前端最近命令显示 `speak` 已完成。

## 6. 边界

- 不接真实 DUIX。
- 不接真实 TTS。
- 不接口型同步。
- 不接真实推流。
- 不接直播平台。
- 不把 device token、OBS 密码、API Key、SQLite 数据库文件提交到仓库。

## 7. 测试覆盖

新增 smoke 覆盖：

- 管理端下发 `speak` 命令。
- 执行端拉取 `speak` 命令。
- 执行端回执 `succeeded`。
- 回执 detail 保存 `adapter=print`。

## 8. 后续建议

- 在 DUIX 官方接口核实后，实现 `DuixAdapter`。
- 将直播中控台人工接管按钮复用到 `/api/executors/:id/speak` 或后续聚合接口。
- 增加执行端命令历史页，便于查看 `speak` / OBS 回执 detail。
- 为 `speak` 命令增加文本长度、敏感词和权限策略。
