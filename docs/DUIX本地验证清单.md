# DUIX 本地验证清单

日期：2026-06-05

本文用于记录后续接入 DUIX 数字人引擎前必须人工核实的事项。本阶段只完成执行端 `DigitalHumanAdapter` 接口与 `DuixAdapter` 占位实现，不接真实 DUIX SDK，不编造未核实 API。

## 1. 起服务方式

待核实：

- DUIX 是否提供本地进程、SDK、HTTP 服务、WebSocket 服务或命令行启动方式。
- 服务启动参数、工作目录、模型/资产目录、日志目录。
- 是否需要管理员权限、虚拟摄像头驱动权限或 GPU 驱动前置条件。
- 进程健康检查方式：端口探活、状态接口、日志关键字或 SDK 回调。

- `TODO(DUIX-1)`：`init(config)` 中启动或连接本地 DUIX runtime/service。
- `TODO(DUIX-6)`：`getStatus()` 中读取真实服务状态和延迟指标。
- `dispose()` 中安全断开或关闭本地资源。

## 2. 文本 / 音频输入接口

待核实：

- DUIX 是否支持直接输入文本并驱动播报。
- 如果只支持音频，TTS 应该由 DUIX 内置还是外部 TTS 生成。
- 单句播报接口是否支持 tone / emotion / speed / volume 等参数。
- 是否支持连续队列、打断当前播报、取消播报。
- 单句输入长度、并发限制、错误码和超时策略。

对应 `DuixAdapter` TODO：

- `TODO(DUIX-2)`：`speak({ text, tone })` 中把后台下发的 `speak` 命令转换为 DUIX 可识别输入。
- 不确认 API 前不得写死任何 DUIX endpoint、method 或参数名。

## 3. 口型 / 表情 / 肢体驱动

待核实：

- 文本或音频输入后，DUIX 是否自动完成口型同步。
- 表情、动作、手势是否可由参数控制，是否支持动作模板。
- 是否支持直播连续播报中的自然待机、打断和恢复。
- 延迟指标：文本下发到画面开始变化的耗时、音画同步误差。

对应 `DuixAdapter` TODO：

- `TODO(DUIX-3)`：将后续命令中的 `tone`、`action` 等字段映射到 DUIX 已验证能力。
- 如果 DUIX 不支持动作参数，适配层需要明确降级。

## 4. 实时流输出方式

待核实：

- DUIX 是否输出窗口、透明背景窗口、虚拟摄像头、NDI、RTMP、WebRTC 或本地视频流。
- 是否可以被 OBS 窗口捕获 / 浏览器源捕获 / 视频采集设备捕获。
- 是否支持竖屏 9:16 和横屏 16:9。
- 是否支持透明背景或绿幕抠像。
- 输出帧率、分辨率、码率、长时间运行稳定性。

- 输出接入应在单独 spike 验证后再落地，避免污染当前执行端协议。

## 5. GPU / 系统要求

待核实：

- Windows / macOS / Linux 支持情况。
- CPU-only 是否可用，是否必须 NVIDIA GPU。
- 最低显存、推荐显卡、驱动版本、CUDA 版本。
- 多开数字人实例时的资源占用。
- 商家直播电脑常见配置能否稳定运行。

## 6. 延迟实测

建议记录：

- 文案下发到 TTS 开始耗时。
- TTS 到口型视频开始耗时。
- 画面进入 OBS 预览耗时。
- 连续 30 分钟 / 2 小时运行掉帧、崩溃、内存增长情况。

验收阈值需后续结合业务决定，当前不要在代码中硬编码未经验证的延迟数字。

## 7. 商用和合规

待核实：

- DUIX 授权模式：私有化买断、按设备、按并发、按小时或按调用。
- 数字人形象、声音克隆、真人授权材料要求。
- 直播平台对数字人标识、AI 生成内容、虚拟主播的合规要求。
- 是否允许接入电商带货场景，是否有行业禁用范围。

## 8. 最小验证路径

建议后续人工 spike：

1. 准备一台直播电脑，安装 OBS 28+ 并开启 obs-websocket。
2. 按 DUIX 官方文档启动本地 DUIX runtime。
3. 用最短文本触发一次播报。
4. 确认 OBS 能捕获 DUIX 输出画面或虚拟摄像头。
5. 记录端到端延迟和稳定性。
6. 再把已核实的调用方式回填到 `executor-client/src/adapters/DuixAdapter.js`。

## 9. 当前结论

- `PrintAdapter` 可以验证后台命令、执行端轮询、回执和前端最近命令展示链路。
- `DuixAdapter` 当前只是占位，不调用任何真实 DUIX API。
- 真实 DUIX 接入必须先完成本文清单中的人工核实，再拆成独立实现任务。
